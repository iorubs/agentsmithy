# Tool-using Assistant

An autonomous agent that calls external MCP tool servers; filesystem,
github, web search; to answer real questions about a project.

> _Available once MCP transports and the MCP toolset land. The
> example will pair an `agentsmithy` agent with one or more
> `mcpsmithy` servers, wired together by a smithy-cli stack file._
